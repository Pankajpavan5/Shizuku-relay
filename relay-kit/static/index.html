⚡ adb without root

Shizuku grants shell (uid 2000) privileges: pm, settings, input, dumpsys, wm, cmd — the full toolbox.

📱 Phone = server

The app hosts the HTTP endpoint itself. Cloud agents can pause or vanish — the link survives on the phone.

🔐 Token-gated

Single shared-secret header, HTTPS-only when tunneled. Your keys, your device, your rules.

🛰️ LAN direct

On the same Wi-Fi the phone answers directly — no tunnel, no internet, no cloud at all.

🧰 Forensics-ready

Live battery telemetry, wake-lock forensics, charging-behaviour analysis — proven in the field.

🤖 Agent-native

One POST per command, synchronous JSON result. MCP tool-wrap in progress.
